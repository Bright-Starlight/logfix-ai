# P0-02 日志上传

## 背景

日志上传是整条排障链路的入口，必须保证操作简单、反馈清晰、结果可追踪。

## 目标

支持用户通过 Web 页面上传一个或多个日志文件，并保存原始文件及上传任务记录。

## 范围

- 拖拽上传
- 文件选择上传
- 多文件批量上传
- 文件类型校验
- 文件大小校验
- 原始文件落地存储
- 上传任务记录

## 不包含

- 日志解析
- 日志聚合

## 支持格式

- `.log`
- `.txt`
- `.json`
- `.zip`

## 输出

- 上传任务记录
- 原始文件保存路径
- 上传状态和错误信息

## 验收标准

- 支持 10MB 内单文件上传
- 支持至少 5 个文件批量上传
- 不支持的文件类型可明确报错
- 上传成功后可追溯原始文件位置

## 依赖

- 项目骨架
- 本地数据目录

## 建议实现

- 上传记录单独建表
- 原始文件名与存储文件名分离，避免命名冲突
