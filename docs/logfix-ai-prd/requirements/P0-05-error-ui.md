# P0-05 异常列表与详情页

## 背景

聚合完成后，需要一个足够直接的界面让用户快速定位主要异常。

## 目标

提供异常列表页和异常详情页，支持基础筛选、搜索和样本查看。

## 范围

- 异常组列表
- 时间过滤
- 级别过滤
- 服务过滤
- 关键词搜索
- 异常详情页
- 日志样本展示

## 不包含

- 高级图表分析
- 手动分组编辑

## 输出

- 异常列表页面
- 异常详情页面

## 验收标准

- 用户可快速定位高频异常
- 用户可进入详情页查看原始样本、统计和时间范围
- 筛选与搜索可正常生效

## 依赖

- 异常聚合结果
- 前端页面框架

## 建议实现

- 列表默认按最近时间和次数排序
- 详情页预留 AI 分析按钮入口
