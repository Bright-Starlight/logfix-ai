# WP-02 异常聚合与基础界面

## 目标

基于已解析日志生成异常组，并提供最小可用的列表页和详情页。

## 合并来源

- P0-04 异常聚合
- P0-05 异常列表与详情页

## 范围

- 生成错误指纹
- 基于 message 和 stack trace 聚合日志
- 计算出现次数、首次时间、最后时间
- 选取代表样本
- 提供异常列表页
- 支持时间、级别、服务过滤
- 支持关键词搜索
- 提供异常详情页
- 展示样本日志和聚合摘要

## 输出

- 异常组表
- 异常组详情页
- 基础排障浏览界面

## 验收标准

- 同类错误可归并为异常组
- 用户能在列表页定位高频异常
- 用户能在详情页查看代表样本和统计信息

## 建议边界

- 首版优先规则聚合
- 先不做手动合并、拆分和高级图表

## 适合的会话目标

一次会话完成后，用户可以从“日志原始记录”切换到“按问题浏览”的排障方式。
