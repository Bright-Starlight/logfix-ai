# WP-04 AI 分析与修复任务生成

## 目标

围绕异常组和相关代码上下文，调用 AI API 生成分析报告，并导出修复任务。

## 合并来源

- P0-08 AI 分析任务执行
- P0-09 修复 Task 生成

## 范围

- 从异常组提取代表日志和上下文
- 检索相关代码文件或片段
- 组装分析 Prompt
- 调用 AI API
- 生成 Markdown 分析报告
- 定义修复任务模板
- 从分析报告提取核心字段
- 生成 Markdown 修复任务
- 支持复制和导出

## 输出

- AI 分析报告
- 修复任务文档

## 验收标准

- 用户可在异常详情页触发 AI 分析
- 报告中包含日志证据与代码路径
- 用户可一键生成修复任务并导出

## 建议边界

- 首版只做同步分析流程
- 首版不做多轮对话和自动代码修复
- Prompt 必须强制模型给出证据链

## 适合的会话目标

一次会话完成后，产品的核心闭环已经打通。
