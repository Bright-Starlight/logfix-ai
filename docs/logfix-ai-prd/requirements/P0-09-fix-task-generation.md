# P0-09 修复 Task 生成

## 背景

AI 分析报告只有转成可执行任务，才能真正缩短修复路径。

## 目标

将 AI 分析结果转成标准化修复任务，支持直接复制或导出给 AI coding agent。

## 范围

- 定义修复任务模板
- 从报告提取核心字段
- 生成 Markdown
- 支持复制
- 支持导出

## 输出格式

- 问题定位
- 根因分析
- 建议修改点
- 影响文件
- 测试验证步骤
- 风险提示

## 不包含

- 自动创建 Git 分支
- 自动提交代码

## 验收标准

- 用户可一键生成任务
- 导出的 Markdown 结构完整
- 任务内容适合直接投喂 Cursor、Aider 或 Continue.dev

## 依赖

- AI 分析报告
- 导出目录

## 建议实现

- 固定标题结构，降低 agent 理解成本
- 可追加 YAML 元数据作为扩展
