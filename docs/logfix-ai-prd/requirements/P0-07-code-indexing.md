# P0-07 代码切分与索引

## 背景

导入仓库后，系统需要将代码转换成可检索的知识片段，供 AI 分析调用。

## 目标

完成代码扫描、切分、embedding 生成和向量存储。
完成代码扫描、基础切分和可检索索引建立。

## 范围

- 扫描仓库文件
- 过滤无关目录和二进制文件
- 文件级索引
- 可选函数级切分
- 保存索引元数据

## 不包含

- 高级 AST 关系图
- 跨仓库依赖分析
- 向量数据库强依赖

## 输出

- 代码 chunk 元数据
- 向量索引记录

## 验收标准

- 可从仓库构建基础索引
- 能按关键词找到相关代码块
- chunk 能映射回原始文件路径

## 依赖

- Git 仓库导入
- 本地文件读取能力

## 建议实现

- 首版优先文件级，函数级作为增强
- 先跳过 `node_modules`、`.git`、构建产物目录
