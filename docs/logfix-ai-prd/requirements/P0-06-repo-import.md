# P0-06 Git 仓库导入

## 背景

没有代码上下文时，AI 对日志的解释容易停留在表面，甚至产生错误推断。

## 目标

支持用户接入一个本地代码仓库目录，为后续代码索引和 AI 分析提供上下文。

## 范围

- 选择本地仓库目录
- 校验目录可读性
- 记录仓库元信息
- 支持手动重新扫描
- 处理目录读取失败

## 不包含

- 多仓库复杂管理
- 自动 Git clone/pull

## 输出

- 仓库目录记录
- 仓库记录
- 扫描状态

## 验收标准

- 至少可成功接入一个本地仓库
- 仓库状态可查看
- 手动重扫可重复执行

## 依赖

- 数据目录

## 建议实现

- 优先接入用户已有本地仓库
- 目录路径使用本地绝对路径记录
