# P0-04 异常聚合

## 背景

原始日志数量大且重复度高，必须聚合成异常组，才能高效进入排查和分析。

## 目标

根据日志 message 与 stack trace 将相似异常聚合，并形成可查询的异常组。

## 范围

- 生成错误指纹
- 相似日志归组
- 计算出现次数
- 计算首次和最后出现时间
- 选取代表样本
- 计算严重度

## 不包含

- 手动合并与拆分
- AI 根因分析

## 输出

- 异常组
- 异常组与日志记录关联关系

## 验收标准

- 同类错误可自动归并
- 列表页可展示聚合结果
- 详情页可查看代表样本和统计摘要

## 依赖

- 日志解析结果
- SQLite 持久化

## 建议实现

- 首版采用规则指纹，不做复杂聚类
- 指纹建议由标准化 message + stack 首帧组成
