# P0-08 AI 分析任务执行

## 背景

LogFix AI 的核心价值不只是展示日志，而是基于证据给出可信的根因分析。

## 目标

围绕一个异常组，检索相关日志与代码上下文，调用本地模型生成结构化分析报告。
围绕一个异常组，检索相关日志与代码上下文，调用 AI API 生成结构化分析报告。

## 范围

- 选取异常组代表样本
- 检索相关日志上下文
- 检索相关代码文件或代码片段
- 组装 RAG Prompt
- 调用 AI API
- 保存 Markdown 报告

## 报告结构

- 问题摘要
- 证据链
- 可能根因
- 影响范围
- 修复建议

## 不包含

- 自动修复代码
- 多轮对话式分析

## 输出

- AI 分析报告
- 分析任务执行状态

## 验收标准

- 用户可从异常详情页触发分析
- 报告中包含具体日志证据
- 报告中包含具体代码位置或文件路径

## 依赖

- 异常聚合
- 代码索引
- AI API 配置

## 建议实现

- Prompt 中强制要求模型引用证据
- 先做同步分析流程，复杂异步队列可后置
