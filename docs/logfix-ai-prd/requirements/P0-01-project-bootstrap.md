# P0-01 项目骨架与基础配置

## 背景

在实现具体业务能力前，需要先搭建一个可持续迭代的本地应用骨架，保证日志、数据库、仓库目录和启动方式统一。

## 目标

建立 LogFix AI 的最小可运行项目结构，支持本地启动、健康检查和 AI API 配置加载。

## 范围

- 初始化后端结构
- 初始化服务端 Web 展示入口
- 提供 `.env.example`
- 初始化 `data/uploads`、`data/repos`、`data/db`、`data/exports`
- 提供启动脚本和健康检查接口

## 不包含

- 具体业务功能
- AI 分析逻辑
- 仓库索引逻辑

## 输入

- 本地 Python 环境
- 本地配置项

## 输出

- 可运行项目骨架
- 基础目录结构
- 健康检查接口
- AI API 基础配置

## 验收标准

- 本地可一条命令启动
- 页面或服务入口可访问
- 数据目录自动创建
- 健康检查返回成功状态

## 依赖

- Python 3.10+
- FastAPI
- Jinja2 / HTMX

## 建议实现

- 后端优先使用 FastAPI
- MVP 前端优先使用 Jinja2 + HTMX
- 使用统一配置模块管理路径和环境变量
