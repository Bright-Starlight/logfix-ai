# WP-01 基础骨架、上传与解析

## 目标

完成一个可启动的最小应用，支持日志上传、基础解析和 SQLite 存储。

## 合并来源

- P0-01 项目骨架与基础配置
- P0-02 日志上传
- P0-03 日志解析

## 范围

- 初始化 FastAPI 项目骨架
- 初始化服务端页面结构
- 配置 `.env.example`
- 初始化 `data/uploads`、`data/db`、`data/exports`
- 提供健康检查接口
- 支持上传 `.log`、`.txt`、`.json`、`.zip`
- 支持多文件上传
- 保存原始文件
- 记录上传任务
- 解析文本日志和 JSON 日志
- 抽取统一字段并保存到 SQLite
- 保留解析失败原文

## 输出

- 可运行应用
- 上传页
- 上传记录
- 日志解析结果表

## 验收标准

- 本地可直接启动
- 上传后原始文件可落盘
- 解析结果成功写入 SQLite
- 无法完整解析的日志不会丢失

## 建议边界

- 首版只覆盖常见单行日志和 JSON 日志
- 多行 stack trace 可先做简单拼接，不追求复杂归并

## 适合的会话目标

一次会话完成后，用户至少能把日志导入系统并看到结构化数据落库。
